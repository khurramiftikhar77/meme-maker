What the Futurama Fry meme means

Fry from Futurama squinting suspiciously. It is used when you cannot tell which of two explanations is true.

How to use it

Write "Not sure if" with the first option at the top and "or" with the second option at the bottom. This template has 2 text boxes.

Futurama Fry caption ideas

  • Not sure if hungry / or just bored
  • Not sure if the code works / or the bug is hiding
  • Not sure if tired / or tired of everything
  • Not sure if they are joking / or I should be worried
  • Not sure if it is a nap / or I am asleep for the night
