What the Success Kid meme means

A baby clenching a fistful of sand with a determined face, from a 2007 photo. It celebrates small, everyday wins.

How to use it

Write a small victory, setting it up on top and paying it off at the bottom. This template has 2 text boxes.

Success Kid caption ideas

  • Found money / in my old jacket
  • Code worked / on the first try
  • Woke up / before my alarm
  • Made it home / before the rain
  • Got the last cookie / nobody noticed

Open the Success Kid template in the editor to use one of these or write your own.
