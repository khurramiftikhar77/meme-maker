What the Waiting Skeleton meme means

A skeleton sitting on a bench, as if someone waited so long they turned to bones. It is used for anything that takes forever.

How to use it

Write "me waiting for" at the top and the slow thing at the bottom. This template has 2 text boxes.

Waiting Skeleton caption ideas

  • Waiting for / the code to compile
  • Me waiting for / my friend who said 5 more minutes

Open the Waiting Skeleton template in the editor to use one of these or write your own.
