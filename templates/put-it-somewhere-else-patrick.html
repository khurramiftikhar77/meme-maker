What the Put It Somewhere Else Patrick meme means

SpongeBob and Patrick arguing about where to put their house. It mocks moving a problem around instead of fixing it.

How to use it

Suggest a real fix on top and have Patrick reply with a way to move the problem somewhere else. This template has 2 text boxes.

Put It Somewhere Else Patrick caption ideas

  • We should fix the bug / No, we move the bug somewhere else
  • We should clean the room / No, we move the mess into the closet
  • We should pay off the debt / No, we put it on another card
  • We should finish the project / No, we push the deadline
  • We should answer the email / No, we mark it unread

Open the Put It Somewhere Else Patrick template in the editor to use one of these or write your own.
